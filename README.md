# Cognitive Collaboration Protocols (人机认知协作契约)

一套面向新一代原生推理模型（GPT-6 / Claude 5.5 / Gemini 4 / Grok 4.7 / DeepSeek-V4）与人类协作者的**双向闭环协议**。

## 核心设计哲学：机器与人类的“镜像非对称”

在人机协作回路中，**模型的上下文窗口**与**人类的生物记忆**遵循完全相反的唤醒机制：

1. **面向机器（`GEMINI.md` / `CHATBOT.md`）—— 去图腾化的高精度动作契约**
   - 模型在每一轮对话都会机械重读 System Prompt。若在提示词中堆砌抽象哲学口号，会引发原生推理模型的“词汇泄漏（掉书袋）”与自适应推理算力空转。
   - 因此，给模型的文档剥离了一切修辞图腾，仅保留模型无法自行推断的**工具调用时序（先检索后落笔）、自治与不可逆边界、反作弊验证与快慢算力分流**。
2. **面向人类（`HUMAN-CONCEPTS.md` / `HUMAN-METAPHOR.md`）—— 唤醒隐性知识的元概念与单主线类比**
   - 人类不会在每次敲击回车前背诵操作清单。机械的条文人类看一遍就会遗忘；真正能在关键决策瞬间唤醒人类直觉的，只有两种载体：
     - **高维跨学科元概念**：通过 `X-Y Problem`、`确认偏误`、`钢铁侠论证`、`委托-代理问题`、`单向门/双向门`、`沉没成本谬误` 等真实存在的跨学科概念锚点，一键点亮大脑中已有的隐性知识库。
     - **“西瓜书”式一以贯之类比**：全篇仅用**“房东请超级包工头装修新房”**这一个生活场景从头串到尾（开工交底 → 审设计图 → 现场施工 → 返工止损），零专业术语，形成肌肉记忆。

## 人机四阶对偶闭环

| 协作阶段 | 人类侧职责 (`HUMAN-*.md`) | 模型侧职责 (`GEMINI.md` / `CHATBOT.md`) |
| :--- | :--- | :--- |
| **1. 破题与求真** | **反 X-Y Problem**：给出真实终局目标与约束底线，不微操具体步骤。 | **先检索后落笔 & 动态核验**：查证本地上下文与一手官方信源，发现前提缺陷直陈更优解。 |
| **2. 推演与去偏** | **零锚定提问 & 红队交叉审查**：隐去个人倾向，用独立会话对冲确认偏误。 | **严守归因红线**：拒绝迎合与事后合理化，主动构建最强反方论点与反证条件。 |
| **3. 决策与边界** | **守住单向门裁判权**：可逆细节充分放权，不可逆边界亲自核验，克服自动化偏见。 | **默认端到端闭环**：可逆任务直接落地，触及删数、破契约、核心依赖与安全/计费边界硬拦截。 |
| **4. 控熵与止损** | **破除沉没成本谬误**：长会话信噪比劣化时果断清空重开，触发双环学习修补规则。 | **最小侵袭 & 精准验证**：禁投机抽象与静默吞错，局部验证防过度测试，简单任务跳过冗余推理。 |
