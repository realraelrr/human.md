# HUMAN.md — 人机协作的人类认知与控制准则（高维概念版）

在人机闭环系统中，模型负责算力搜索与局部收敛，**人类负责定义目标函数、守护不可逆边界与执行证伪裁决**。这份文档不是写给机器的提示词，而是面向人类协作者自身的**元认知唤醒锚点**——用于克制人类的诱导本能、微操冲动与认知偷懒（Automation Bias）。

---

### 1. 意图解耦：终局思维（Backcasting） + 第一性原理 + 反 X-Y Problem
- **核心盲区**：人类最常犯的错误是陷入 **X-Y Problem**——本想解决核心问题 `X`，却死锁在自己拍脑袋想出的次优办法 `Y` 上，命令模型去实现 `Y`，用自己狭隘的已知路径阉割了模型的全局搜索空间。
- **操作准则**：下达指令时遵循**控制反转（Inversion of Control）**——向模型输入「终局状态（End-state）、第一性约束与可观察的验收标准（Operationalization）」，把具体实现路径留给模型探索；若你指定了做法 `Y`，必须同步告知背后的真实目的 `X`，明确授权模型证伪你的做法。

### 2. 求真去偏：克服确认偏误（Confirmation Bias） + 钢铁侠论证（Steelmanning） + 红队交叉检验（Red Teaming）
- **核心盲区**：模型天然具有迎合性（Sycophancy）。若人类带着预设立场提问（**诱导性提问 / Leading the Witness**），模型就会成为放大人类**确认偏误**的回音室，为你编织精美的确证牢笼。
- **操作准则**：面对未定决策时采用**零锚定提问**，主动要求模型对反方观点进行**钢铁侠论证（Steelmanning，构建最强反方逻辑而非攻击稻草人）**；对关键架构或核心方案，开启无历史上下文污染的独立会话进行**盲测与红队交叉审查（Clean-Context Cross-Examination）**，人类居中做证据裁决。

### 3. 主权边界：委托-代理问题（Principal-Agent Problem） + 单向门/双向门法则 + 反自动化偏见（Anti-Automation Bias）
- **核心盲区**：在**委托-代理关系**中，模型是执行代理人（Agent），人类是承担一切现实后果的委托人（Principal）。模型输出越流畅，人类越容易产生**自动化偏见（Automation Bias）**，退化为无脑放行的橡皮图章。
- **操作准则**：
  - **双向门（Two-Way Doors，可逆、局部试错）**：遵循**奥卡姆剃刀**与充分授权，让模型端到端闭环，克制微观管理欲；
  - **单向门（One-Way Doors，不可逆的数据销毁、核心契约/Schema、安全与资金边界）**：主权不可让渡，人类必须亲自完成**波普尔可证伪性（Falsifiability）**核验后再签字放行。

### 4. 上下文控熵：信息熵增定律（Information Entropy） + 破除沉没成本谬误（Sunk Cost Fallacy） + 双环学习（Double-Loop Learning）
- **核心盲区**：长对话必然伴随**信息熵增**与**路径依赖（Path Dependence）**——错误前提与修正补丁交织越深，信噪比越劣化；而人类的**沉没成本谬误**会驱使自己在已经浑浊的上下文里盲目纠缠。
- **操作准则**：当对话陷入反复拉锯或连续报错时，立即斩断沉没成本：提炼已验证的客观事实，果断开启**干净上下文（Fresh Context）**重新开局；并触发**阿吉里斯双环学习（Double-Loop Learning）**——不只修补单次输出，而是反躬自省：是不是我给出的初始约束或全局规则存在系统性漏洞？
